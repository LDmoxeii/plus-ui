# 项目配置文件详解

本文档详细讲解项目中各个配置文件的作用、配置项含义和最佳实践。

## 📋 配置文件概览

| 文件名 | 作用 | 影响范围 |
|-------|------|---------|
| `.editorconfig` | 统一编辑器代码格式 | 所有编辑器 |
| `.env.development` | 开发环境变量 | 开发环境 |
| `.env.production` | 生产环境变量 | 生产环境 |
| `.eslintrc-auto-import.json` | ESLint 自动导入全局变量 | ESLint |
| `.prettierignore` | Prettier 忽略文件 | Prettier |
| `.prettierrc` | Prettier 代码格式化规则 | Prettier |
| `eslint.config.ts` | ESLint 代码检查规则 | ESLint |
| `tsconfig.json` | TypeScript 编译配置 | TypeScript |
| `uno.config.ts` | UnoCSS 原子化 CSS 配置 | 样式 |
| `vite.config.ts` | Vite 构建工具配置 | 构建和开发 |

## 1. .editorconfig - 编辑器配置

### 作用
统一不同编辑器（VS Code、WebStorm、Sublime 等）的代码格式，确保团队成员使用一致的编码风格。

### 配置内容
```ini
# 告诉 EditorConfig 插件，这是根文件，不用继续往上查找
root = true

# 匹配全部文件
[*]
# 缩进风格：space（空格）或 tab（制表符）
indent_style = space
# 缩进的空格数
indent_size = 2
# 设置字符集
charset = utf-8
# 结尾换行符：lf（Linux/Mac）、cr（旧Mac）、crlf（Windows）
end_of_line = lf
# 删除一行中的前后空格
trim_trailing_whitespace = true
# 在文件结尾插入新行
insert_final_newline = true

# Markdown 文件特殊配置
[*.md]
insert_final_newline = false
trim_trailing_whitespace = false
```

### 配置项详解

| 配置项 | 值 | 说明 |
|-------|---|------|
| `indent_style` | `space` | 使用空格缩进（推荐，避免不同编辑器显示不一致） |
| `indent_size` | `2` | 每次缩进 2 个空格（前端项目常用） |
| `charset` | `utf-8` | 使用 UTF-8 字符编码（支持中文等） |
| `end_of_line` | `lf` | 使用 Linux/Mac 换行符（Git 推荐） |
| `trim_trailing_whitespace` | `true` | 自动删除行尾空格 |
| `insert_final_newline` | `true` | 文件末尾自动添加空行（Git 最佳实践） |

### 为什么需要？
- ✅ 团队协作时统一代码格式
- ✅ 避免因编辑器不同导致的格式差异
- ✅ 减少 Git 提交时的无意义差异（如空格、换行符）

### VS Code 使用
安装插件：**EditorConfig for VS Code**

## 2. 环境变量配置 (.env 文件)

### 作用
为不同环境（开发、生产）配置不同的参数，如 API 地址、端口号、功能开关等。

### 2.1 .env.development - 开发环境

```bash
# 页面标题
VITE_APP_TITLE = RuoYi-Vue-Plus多租户管理系统
VITE_APP_LOGO_TITLE = RuoYi-Vue-Plus

# 开发环境标识
VITE_APP_ENV = 'development'

# API 基础路径（会被代理到后端）
VITE_APP_BASE_API = '/dev-api'

# 应��访问路径（如：/admin/）
VITE_APP_CONTEXT_PATH = '/'

# 监控地址
VITE_APP_MONITOR_ADMIN = 'http://localhost:9090/admin/applications'

# SnailJob 控制台地址
VITE_APP_SNAILJOB_ADMIN = 'http://localhost:8800/snail-job'

# 开发服务器端口
VITE_APP_PORT = 80

# 接口加密功能开关
VITE_APP_ENCRYPT = true

# RSA 公钥（前端加密用）
VITE_APP_RSA_PUBLIC_KEY = 'MFww...'

# RSA 私钥（前端解密用）
VITE_APP_RSA_PRIVATE_KEY = 'MIIB...'

# 客户端 ID（多租户标识）
VITE_APP_CLIENT_ID = 'e5cd7e4891bf95d1d19206ce24a7b32e'

# WebSocket 开关
VITE_APP_WEBSOCKET = false

# SSE（服务器推送）开关
VITE_APP_SSE = true
```

### 2.2 .env.production - 生产环境

```bash
# 生产环境标识
VITE_APP_ENV = 'production'

# 生产环境 API 路径
VITE_APP_BASE_API = '/prod-api'

# 监控地址（使用相对路径）
VITE_APP_MONITOR_ADMIN = '/admin/applications'

# 是否在打包时开启压缩（gzip 或 brotli）
VITE_BUILD_COMPRESS = gzip

# 其他配置同开发环境...
```

### 环境变量使用

#### 在代码中访问
```typescript
// 获取环境变量
const apiUrl = import.meta.env.VITE_APP_BASE_API        // '/dev-api'
const title = import.meta.env.VITE_APP_TITLE            // 'RuoYi-Vue-Plus...'
const isEncrypt = import.meta.env.VITE_APP_ENCRYPT      // true

// 判断当前环境
const isDev = import.meta.env.DEV        // 开发环境为 true
const isProd = import.meta.env.PROD      // 生产环境为 true
const mode = import.meta.env.MODE        // 'development' 或 'production'
```

#### 在配置文件中访问
```typescript
// vite.config.ts
export default defineConfig(({ mode }) => {
  const env = loadEnv(mode, process.cwd())

  return {
    base: env.VITE_APP_CONTEXT_PATH,
    server: {
      port: Number(env.VITE_APP_PORT)
    }
  }
})
```

### 重要规则

1. **必须以 `VITE_` 开头** - 只有这样的变量才会被暴露给客户端代码
2. **不要提交敏感信息** - 如真实的数据库密码、API 密钥等
3. **修改后需重启** - 修改 .env 文件后需要重启开发服务器

## 3. .eslintrc-auto-import.json - 自动导入全局变量

### 作用
告诉 ESLint 哪些变量是全局可用的（由 `unplugin-auto-import` 自动导入），避免 ESLint 报"未定义变量"错误。

### 内容示例
```json
{
  "globals": {
    "ref": true,                  // Vue 3 响应式 API
    "computed": true,             // 计算属性
    "watch": true,                // 监听器
    "onMounted": true,            // 生命周期钩子
    "useRouter": true,            // Vue Router
    "useRoute": true,             // 当前路由
    "defineStore": true,          // Pinia Store
    "ElMessage": true,            // Element Plus 消息提示
    "ElMessageBox": true,         // Element Plus 对话框
    "ElLoading": true,            // Element Plus 加载
    "ElNotification": true        // Element Plus 通知
    // ... 还有很多
  }
}
```

### 为什么需要？

**没有这个配置时：**
```typescript
// ESLint 会报错：'ref' is not defined
const count = ref(0)  // ❌ ESLint 错误
```

**有了这个配置后：**
```typescript
// ESLint 知道 ref 是全局变量，不会报错
const count = ref(0)  // ✅ 正常
```

### 自动生成
这个文件由 `unplugin-auto-import` 插件自动生成和更新，**不需要手动编辑**。

## 4. Prettier 配置

### 4.1 .prettierignore - 忽略文件

告诉 Prettier 哪些文件不需要格式化。

```
/dist/*              # 打包输出目录
.local               # 本地文件
.output.js           # 输出文件
/node_modules/**     # 依赖包
**/*.svg             # SVG 图片
**/*.sh              # Shell 脚本
/public/*            # 公共资源
```

### 4.2 .prettierrc - 格式化规则

定义代码格式化的具体规则。

```json
{
  "printWidth": 150,              // 每行最大字符数
  "tabWidth": 2,                  // 缩进空格数
  "useTabs": false,               // 使用空格而非 Tab
  "semi": true,                   // 语句末尾加分号
  "singleQuote": true,            // 使用单引号
  "quoteProps": "preserve",       // 对象属性引号保持原样
  "jsxSingleQuote": false,        // JSX 使用双引号
  "bracketSameLine": false,       // 标签闭合符号换行
  "trailingComma": "none",        // 不添加尾随逗号
  "bracketSpacing": true,         // 对象大括号内加空格 { foo: bar }
  "arrowParens": "always",        // 箭头函数参数总是加括号 (x) => x
  "endOfLine": "auto"             // 换行符自动检测
}
```

### 配置项详解

| 配置项 | 值 | 效果 |
|-------|---|------|
| `printWidth` | `150` | 一行超过 150 字符就换行 |
| `semi` | `true` | `const a = 1;` ✅ vs `const a = 1` ❌ |
| `singleQuote` | `true` | `'hello'` ✅ vs `"hello"` ❌ |
| `trailingComma` | `none` | `{ a: 1 }` ✅ vs `{ a: 1, }` ❌ |
| `arrowParens` | `always` | `(x) => x` ✅ vs `x => x` ❌ |

### 使用方式

#### 命令行格式化
```bash
# 格式化所有文件
npm run prettier

# 检查格式（不修改）
npx prettier --check .
```

#### VS Code 自动格式化
```json
// settings.json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode"
}
```

## 5. eslint.config.ts - ESLint 配置

### 作用
定义代码质量检查规则，发现潜在错误和不规范的代码。

### 配置内容
```typescript
import pluginVue from 'eslint-plugin-vue'
import { defineConfigWithVueTs } from '@vue/eslint-config-typescript'
import skipFormatting from '@vue/eslint-config-prettier/skip-formatting'

export default defineConfigWithVueTs(
  // 检查哪些文件
  {
    files: ['**/*.{js,cjs,ts,mts,tsx,vue}']
  },

  // 忽略哪些文件
  {
    ignores: ['**/dist/**', '**/dist-ssr/**', '**/coverage/**']
  },

  // Vue 插件配置
  pluginVue.configs['flat/essential'],

  // TypeScript 配置
  vueTsConfigs.recommended,

  // 跳过与 Prettier 冲突的规则
  skipFormatting,

  // 自定义规则
  {
    rules: {
      '@typescript-eslint/no-empty-function': 'off',      // 允许空函数
      '@typescript-eslint/no-explicit-any': 'off',        // 允许使用 any
      '@typescript-eslint/no-unused-vars': 'off',         // 允许未使用的变量
      'vue/multi-word-component-names': 'off',            // 允许单词组件名
      'prettier/prettier': 'error'                        // Prettier 错误视为 ESLint 错误
    }
  }
)
```

### 规则级别

- `'off'` 或 `0` - 关闭规则
- `'warn'` 或 `1` - 警告（不影响构建）
- `'error'` 或 `2` - 错误（阻止构建）

### 使用方式

#### 命令行检查
```bash
# 检查代码
npm run lint:eslint

# 自动修复
npm run lint:eslint:fix
```

#### VS Code 集成
安装插件：**ESLint**

```json
// settings.json
{
  "eslint.validate": ["javascript", "typescript", "vue"],
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": true
  }
}
```

## 6. tsconfig.json - TypeScript 配置

### 作用
配置 TypeScript 编译器的行为和类型检查规则。

### 配置内容
```json
{
  "compilerOptions": {
    // 基础配置
    "baseUrl": ".",                          // 模块解析基础目录
    "target": "ES2020",                      // 编译目标（ES2020）
    "module": "ESNext",                      // 模块系统（ESNext）
    "moduleResolution": "Bundler",           // 模块解析策略
    "lib": ["ESNext", "DOM", "DOM.Iterable"], // 引入的类型库

    // 严格模式
    "strict": true,                          // 启用所有严格检查
    "noImplicitAny": false,                  // 关闭：允许隐式 any
    "strictFunctionTypes": false,            // 关闭：严格函数类型检查
    "strictNullChecks": false,               // 关闭：严格空值检查

    // 模块相关
    "allowJs": true,                         // 允许编译 JS 文件
    "resolveJsonModule": true,               // 允许导入 JSON
    "esModuleInterop": true,                 // ES 模块互操作

    // 路径别名
    "paths": {
      "@/*": ["./src/*"]                     // @ 指向 src 目录
    },

    // 其他
    "skipLibCheck": true,                    // 跳过类型声明文件检查
    "noEmit": true,                          // 不输出文件（由 Vite 处理）
    "jsx": "preserve",                       // 保留 JSX（由 Vite 处理）
    "sourceMap": true,                       // 生成 source map
    "removeComments": true,                  // 移除注释
    "experimentalDecorators": true,          // 启用装饰器
    "forceConsistentCasingInFileNames": true // 强制文件名大小写一致
  },

  // 包含哪些文件
  "include": [
    "src/**/*.ts",
    "src/**/*.vue",
    "vite.config.ts",
    "eslint.config.ts"
  ],

  // 排除哪些文件
  "exclude": ["node_modules", "dist"]
}
```

### 重要配置项

| 配置项 | 说明 | 推荐值 |
|-------|------|--------|
| `strict` | 启用所有严格检查 | `true` |
| `noImplicitAny` | 禁止隐式 any | 学习阶段可设为 `false` |
| `strictNullChecks` | 严格空值检查 | `true`（本项目为 `false`） |
| `skipLibCheck` | 跳过库文件类型检查（加快编译） | `true` |
| `paths` | 路径别名配置 | `{"@/*": ["./src/*"]}` |

## 7. uno.config.ts - UnoCSS 配置

### 作用
配置 UnoCSS 原子化 CSS 框架，定义快捷类名和主题。

### 配置内容
```typescript
import {
  defineConfig,
  presetUno,           // 默认预设（类似 Tailwind）
  presetAttributify,   // 属性化模式
  presetIcons,         // 图标预设
  presetTypography,    // 排版预设
  presetWebFonts       // Web 字体
} from 'unocss'

export default defineConfig({
  // 自定义快捷类名
  shortcuts: {
    'panel-title': 'pb-[5px] font-medium text-base text-[#6379bb] border-b mb-5'
  },

  // 主题配置
  theme: {
    colors: {
      primary: 'var(--el-color-primary)',           // 使用 Element Plus 主题色
      primary_dark: 'var(--el-color-primary-light-5)'
    }
  },

  // 预设
  presets: [
    presetUno(),
    presetAttributify(),
    presetIcons(),
    presetTypography(),
    presetWebFonts({ fonts: {} })
  ]
})
```

### UnoCSS 使用示例

#### 基础类名
```vue
<template>
  <!-- 布局 -->
  <div class="flex items-center justify-between">

  <!-- 尺寸 -->
  <div class="w-full h-100px p-4 m-2">

  <!-- 文本 -->
  <span class="text-lg font-bold text-primary">

  <!-- 响应式 -->
  <div class="md:w-1/2 lg:w-1/3">
</template>
```

#### 自定义快捷类
```vue
<template>
  <!-- 使用自定义的 panel-title -->
  <h3 class="panel-title">面板标题</h3>
</template>
```

## 8. vite.config.ts - Vite 配置

### 作用
配置 Vite 构建工具，包括开发服务器、构建选项、插件等。

### 配置内容
```typescript
import { defineConfig, loadEnv } from 'vite'
import vue from '@vitejs/plugin-vue'
import path from 'path'

export default defineConfig(({ mode }) => {
  // 加载环境变量
  const env = loadEnv(mode, process.cwd())

  return {
    // 基础路径
    base: env.VITE_APP_CONTEXT_PATH,

    // 路径别名
    resolve: {
      alias: {
        '@': path.resolve(__dirname, './src')
      }
    },

    // 插件
    plugins: [
      vue(),
      // ... 其他插件
    ],

    // 开发服务器
    server: {
      host: '0.0.0.0',                    // 监听所有地址
      port: Number(env.VITE_APP_PORT),    // 端口号（80）
      open: true,                         // 自动打开浏览器

      // API 代理
      proxy: {
        '/dev-api': {
          target: 'http://localhost:8080',  // 后端地址
          changeOrigin: true,               // 改变源
          ws: true,                         // 支持 WebSocket
          rewrite: (path) => path.replace(/^\/dev-api/, '')
        }
      }
    },

    // CSS 配置
    css: {
      preprocessorOptions: {
        scss: {
          api: 'modern-compiler'  // 使用现代 SCSS 编译器
        }
      }
    },

    // 预构建优化
    optimizeDeps: {
      include: [
        'vue',
        'vue-router',
        'pinia',
        'axios',
        'element-plus/es/components/**/css'
      ]
    }
  }
})
```

### 重要配置项

#### 1. 开发服务器代理
```typescript
server: {
  proxy: {
    '/dev-api': {
      target: 'http://localhost:8080',
      changeOrigin: true,
      rewrite: (path) => path.replace(/^\/dev-api/, '')
    }
  }
}
```

**工作原理：**
```
前端请求：/dev-api/system/user/list
↓
代理转发：http://localhost:8080/system/user/list
```

#### 2. 路径别名
```typescript
resolve: {
  alias: {
    '@': path.resolve(__dirname, './src')
  }
}
```

#### 3. 构建优化
```typescript
build: {
  rollupOptions: {
    output: {
      manualChunks: {
        'element-plus': ['element-plus'],  // 单独打包 Element Plus
        'vue': ['vue', 'vue-router', 'pinia']
      }
    }
  }
}
```

## ❓ 常见问题

### 1. 修改 .env 文件不生效？
**原因**：环境变量在启动时加载，运行时不会重新读取。
**解决**：重启开发服务器 `npm run dev`

### 2. ESLint 报错：'ref' is not defined
**原因**：`.eslintrc-auto-import.json` 未生成或过期。
**解决**：删除该文件，重启项目，会自动重新生成。

### 3. Prettier 和 ESLint 冲突？
**原因**：两者规则不一致。
**解决**：使用 `@vue/eslint-config-prettier/skip-formatting` 跳过冲突规则。

### 4. TypeScript 报错：找不到模块 '@/xxx'
**原因**：路径别名未正确配置。
**解决**：检查 `tsconfig.json` 中的 `paths` 配置，重启 TypeScript 服务。

### 5. UnoCSS 类名不生效？
**原因**：类名未被扫描到。
**解决**：确保文件在 `uno.config.ts` 的扫描范围内，重启开发服务器。

---

通过理解这些配置文件，你能更好地控制项目的开发环境、构建过程和代码质量！🚀

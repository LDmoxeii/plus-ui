# 基础概念详解

本文档详细讲解项目中的三个核心概念：路径别名、自定义指令、VXE-Table。

## 1. @ 符号 - 路径别名

### 什么是路径别名？

`@` 是一个**路径别名**（Path Alias），它代表 `src` 目录的绝对路径。

### 配置位置

#### Vite 配置 (vite.config.ts)
```typescript
export default defineConfig(({ mode, command }) => {
  return {
    resolve: {
      alias: {
        '@': path.resolve(__dirname, './src')  // @ 指向 src 目录
      }
    }
  }
})
```

#### TypeScript 配置 (tsconfig.json)
```json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]  // 让 TypeScript 识别 @ 路径
    }
  }
}
```

### 为什么需要路径别名？

**❌ 使用相对路径的问题：**
```typescript
// 文件层级深了很麻烦，容易出错
import { useUserStore } from '../../../store/modules/user'
import { getToken } from '../../../../utils/auth'
import MyComponent from '../../../components/MyComponent.vue'

// 如果文件移动位置，所有相对路径都要改
```

**✅ 使用 @ 路径的优势：**
```typescript
// 清晰、不会出错、不受文件位置影响
import { useUserStore } from '@/store/modules/user'
import { getToken } from '@/utils/auth'
import MyComponent from '@/components/MyComponent.vue'

// 文件移动后，这些路径不需要修改
```

### 实际应用示例

在 `src/main.ts` 中：
```typescript
// @ 路径（推荐）
import '@/assets/styles/index.scss'     // 等价于 src/assets/styles/index.scss
import store from '@/store'             // 等价于 src/store
import router from '@/router'           // 等价于 src/router

// 相对路径（当前目录下的文件）
import App from './App.vue'             // 当前目录的 App.vue
```

### 常见用法

```typescript
// 导入 Store
import { useUserStore } from '@/store/modules/user'
import { usePermissionStore } from '@/store/modules/permission'

// 导入工具函数
import { parseTime, handleTree } from '@/utils/ruoyi'
import { getToken, setToken } from '@/utils/auth'

// 导入 API
import { listUser, addUser } from '@/api/system/user'
import { login, logout } from '@/api/login'

// 导入组件
import Pagination from '@/components/Pagination/index.vue'
import DictTag from '@/components/DictTag/index.vue'

// 导入类型
import type { UserInfo } from '@/api/types'

// 导入样式
import '@/assets/styles/custom.scss'
```

### 注意事项

1. **只在 .ts、.vue 文件中使用** - @ 路径不能在 HTML 或纯 CSS 文件中使用
2. **配置生效需要重启开发服务器** - 修改配置后需要 `npm run dev` 重新启动
3. **IDE 智能提示** - VS Code 安装 Volar 插件后会有路径提示

## 2. 自定义指令

### 什么是指令？

**指令（Directive）** 是 Vue 提供的一种特殊属性，用于对 DOM 元素进行底层操作。

### Vue 内置指令

你可能已经见过这些：
```vue
<template>
  <!-- 条件渲染 -->
  <div v-if="show">显示内容</div>
  <div v-show="visible">显示/隐藏</div>

  <!-- 列表渲染 -->
  <li v-for="item in list" :key="item.id">{{ item.name }}</li>

  <!-- 双向绑定 -->
  <input v-model="text" />

  <!-- 事件监听 -->
  <button @click="handleClick">点击</button>

  <!-- 动态属性 -->
  <div :class="{ active: isActive }">动态类名</div>
  <img :src="imageUrl" />
</template>
```

### 2.1 v-hasPermi - 权限控制指令

#### 作用
根据用户权限显示/隐藏元素

#### 实现代码 (src/directive/permission/index.ts)
```typescript
export const hasPermi: Directive = {
  mounted(el: HTMLElement, binding: DirectiveBinding) {
    const { permissions } = useUserStore()
    const { value } = binding

    if (value && value instanceof Array && value.length > 0) {
      // 检查用户是否拥有超级权限 *:*:* 或指定的权限
      const hasPermission = permissions.some((permi: string) => {
        return permi === '*:*:*' || value.includes(permi)
      })

      // 没有权限，从 DOM 中移除元素
      if (!hasPermission) {
        el.parentNode && el.parentNode.removeChild(el)
        return false
      }
    }
  }
}
```

#### 使用方式
```vue
<template>
  <!-- 只有拥有指定权限的用户才能看到这个按钮 -->
  <el-button v-hasPermi="['system:user:add']">
    新增用户
  </el-button>

  <!-- 需要多个权限之一（满足其中一个即可） -->
  <el-button v-hasPermi="['system:user:edit', 'system:user:update']">
    编辑用户
  </el-button>

  <!-- 应用在任何元素上 -->
  <div v-hasPermi="['system:config:edit']">
    <span>配置管理区域</span>
  </div>
</template>
```

#### 工作原理
1. 从 `useUserStore()` 获取当前用户的权限列表
2. 检查用户是否拥有超级权限 `*:*:*` 或指定的权限
3. 如果没有权限，直接从 DOM 中移除该元素（`el.parentNode.removeChild(el)`）
4. 用户在页面上看不到这个元素（不是隐藏，是完全不存在）

#### 权限标识格式
- 格式：`模块:功能:操作`
- 示例：
  - `system:user:add` - 系统模块 > 用户管理 > 新增
  - `system:user:edit` - 系统模块 > 用户管理 > 编辑
  - `system:user:remove` - 系统模块 > 用户管理 > 删除
  - `*:*:*` - 超级权限（所有权限）

### 2.2 v-hasRoles - 角色控制指令

#### 作用
根据用户角色显示/隐藏元素

#### 实现代码
```typescript
export const hasRoles: Directive = {
  mounted(el: HTMLElement, binding: DirectiveBinding) {
    const { value } = binding
    const { roles } = useUserStore()

    if (value && value instanceof Array && value.length > 0) {
      // 检查用户是否是超级管理员、管理员或指定的角色
      const hasRole = roles.some((role: string) => {
        return role === 'superadmin' || role === 'admin' || value.includes(role)
      })

      // 不是指定角色，移除元素
      if (!hasRole) {
        el.parentNode && el.parentNode.removeChild(el)
        return false
      }
    }
  }
}
```

#### 使用方式
```vue
<template>
  <!-- 只有管理员才能看到 -->
  <el-button v-hasRoles="['admin']">
    管理员功能
  </el-button>

  <!-- 多个角色之一（满足其中一个即可） -->
  <div v-hasRoles="['admin', 'editor', 'operator']">
    高级功能区域
  </div>

  <!-- 普通用户功能 -->
  <el-button v-hasRoles="['user']">
    普通功能
  </el-button>
</template>
```

#### 工作原理
1. 从 `useUserStore()` 获取当前用户的角色列表
2. 检查用户是否是 `superadmin`、`admin` 或指定的角色
3. 如果不符合，移除元素

#### 角色类型
- `superadmin` - 超级管理员（最高权限）
- `admin` - 管理员
- `editor` - 编辑者
- `user` - 普通用户
- 自定义角色（根据后端配置）

### 2.3 v-copyText - 复制文本指令

#### 作用
点击元素时复制指定文本到剪贴板

#### 实现代码 (src/directive/common/copyText.ts)
```typescript
export default {
  beforeMount(el: any, { value, arg }: DirectiveBinding) {
    if (arg === 'callback') {
      // 保存回调函数
      el.$copyCallback = value
    } else {
      // 保存要复制的值
      el.$copyValue = value

      // 绑定点击事件
      const handler = () => {
        copyTextToClipboard(el.$copyValue)
        if (el.$copyCallback) {
          el.$copyCallback(el.$copyValue)
        }
      }
      el.addEventListener('click', handler)

      // 保存清理函数
      el.$destroyCopy = () => el.removeEventListener('click', handler)
    }
  }
}

// 复制到剪贴板的实现
function copyTextToClipboard(input: string) {
  // 1. 创建隐藏的 textarea
  const element = document.createElement('textarea')
  element.value = input
  element.setAttribute('readonly', '')
  element.style.position = 'absolute'
  element.style.left = '-9999px'

  // 2. 添加到页面
  document.body.append(element)

  // 3. 选中文本
  element.select()
  element.selectionStart = 0
  element.selectionEnd = input.length

  // 4. 执行复制命令
  let isSuccess = false
  try {
    isSuccess = document.execCommand('copy')
  } catch (err) {
    console.error('复制失败', err)
  }

  // 5. 清理
  element.remove()

  return isSuccess
}
```

#### 使用方式
```vue
<template>
  <!-- 基础用法：点击复制文本 -->
  <el-button v-copyText="'这是要复制的内容'">
    点击复制
  </el-button>

  <!-- 复制变量内容 -->
  <span v-copyText="userEmail">{{ userEmail }}</span>

  <!-- 带回调函数：复制成功后的提示 -->
  <el-button
    v-copyText="apiKey"
    v-copyText:callback="handleCopySuccess"
  >
    复制 API Key
  </el-button>

  <!-- 实用场景：复制用户 ID -->
  <el-tag
    v-copyText="user.userId"
    v-copyText:callback="() => ElMessage.success('已复制用户ID')"
    style="cursor: pointer"
  >
    用户ID: {{ user.userId }}
  </el-tag>
</template>

<script setup lang="ts">
const userEmail = ref('user@example.com')
const apiKey = ref('sk-1234567890abcdef')

const handleCopySuccess = (text: string) => {
  ElMessage.success(`已复制: ${text}`)
}
</script>
```

#### 工作原理
1. 创建一个隐藏的 `<textarea>` 元素
2. 将要复制的文本放入其中
3. 选中文本
4. 执行浏览器的复制命令 `document.execCommand('copy')`
5. 清理临时元素
6. 如果设置了回调函数，执行回调

### 自定义指令的生命周期钩子

```typescript
export default {
  // 在绑定元素的父组件挂载之前调用
  beforeMount(el, binding, vnode) {
    console.log('beforeMount')
  },

  // 绑定元素的父组件挂载时调用
  mounted(el, binding, vnode) {
    console.log('mounted')
  },

  // 在包含组件的 VNode 更新之前调用
  beforeUpdate(el, binding, vnode, prevVnode) {
    console.log('beforeUpdate')
  },

  // 在包含组件的 VNode 及其子组件的 VNode 更新之后调用
  updated(el, binding, vnode, prevVnode) {
    console.log('updated')
  },

  // 在绑定元素的父组件卸载之前调用
  beforeUnmount(el, binding, vnode) {
    console.log('beforeUnmount')
  },

  // 绑定元素的父组件卸载时调用
  unmounted(el, binding, vnode) {
    console.log('unmounted')
  }
}
```

#### 钩子参数说明

- **el**: 指令绑定到的元素（DOM 元素）
- **binding**: 包含以下属性的对象
  - `value`: 传递给指令的值，如 `v-hasPermi="['system:user:add']"` 中的数组
  - `oldValue`: 之前的值（仅在 `beforeUpdate` 和 `updated` 中可用）
  - `arg`: 传递给指令的参数，如 `v-copyText:callback` 中的 `callback`
  - `modifiers`: 修饰符对象，如 `v-focus.lazy` 中的 `{ lazy: true }`
- **vnode**: Vue 编译生成的虚拟节点
- **prevVnode**: 上一个虚拟节点（仅在 `beforeUpdate` 和 `updated` 中可用）

#### 示例 2：防抖指令

```typescript
// src/directive/common/debounce.ts
import { Directive } from 'vue'

const debounce: Directive = {
  mounted(el: HTMLElement, binding) {
    const { value, arg } = binding
    const delay = parseInt(arg || '300') // 默认 300ms

    let timer: any = null

    el.addEventListener('click', () => {
      if (timer) clearTimeout(timer)

      timer = setTimeout(() => {
        value()
      }, delay)
    })
  }
}

export default debounce
```

```vue
<!-- 使用 -->
<template>
  <!-- 点击后 500ms 才执行 -->
  <el-button v-debounce:500="handleSubmit">
    提交表单
  </el-button>
</template>
```

#### 示例 3：图片懒加载指令

```typescript
// src/directive/common/lazy.ts
import { Directive } from 'vue'

const lazy: Directive = {
  mounted(el: HTMLImageElement, binding) {
    const { value } = binding

    const observer = new IntersectionObserver((entries) => {
      entries.forEach((entry) => {
        if (entry.isIntersecting) {
          // 图片进入视口
          el.src = value
          observer.unobserve(el)
        }
      })
    })

    observer.observe(el)
  }
}

export default lazy
```


## 3. VXE-Table 详解

### 什么是 VXE-Table？

**VXE-Table** 是一个功能强大的 Vue 表格组件库，专门用于处理**大数据量**和**复杂表格**场景。

### 为什么需要 VXE-Table？

Element Plus 的 `<el-table>` 适合常规表格，但数据量大时（如超过 1000 行）性能会显著下降。

VXE-Table 通过**虚拟滚动**技术，可以流畅渲染**10万+** 行数据。

### 项目中的配置 (src/main.ts)

```typescript
// 导入 VXE-Table
import VXETable from 'vxe-table'
import 'vxe-table/lib/style.css'

// 全局配置
VXETable.setConfig({
  zIndex: 999999  // 设置表格弹层的 z-index
})

// 注册
app.use(VXETable)
```

---

### VXE-Table 核心特性

#### 1. 虚拟滚动
只渲染可见区域的行，大数据量下性能优异

```vue

  <vxe-column field="name" title="姓名" />
  <vxe-column field="age" title="年龄" />
```

### 什么时候使用 VXE-Table？

#### ✅ 适合使用 VXE-Table 的场景

1. **大数据量** - 数据超过 500 行
2. **单元格编辑** - 需要表格内直接编辑
3. **导入导出** - 需要导入/导出 Excel
4. **复杂交互** - 拖拽排序、行合并等
5. **保留选中** - 翻页后需要保留选中状态
6. **树形数据** - 复杂的树形表格展示
7. **高性能要求** - 对渲染性能有严格要求

#### ✅ 继续使用 Element Plus Table 的场景

1. **简单展示** - 数据量少（< 200 行）
2. **基础 CRUD** - 简单的增删改查表格
3. **轻量级** - 追求项目体积最小化
4. **快速开发** - 不需要复杂交互
5. **团队熟悉** - 团队对 Element Plus 更熟悉

## 📝 总结

### 1. @ 符号（路径别名）
- 代表 `src` 目录的绝对路径
- 避免复杂的相对路径 `../../../`
- 配置在 `vite.config.ts` 和 `tsconfig.json`
- 使代码更清晰、更易维护

### 2. 自定义指令
项目包含 3 个自定义指令：

| 指令 | 作用 | 示例 |
|-----|------|------|
| `v-hasPermi` | 权限控制 | `v-hasPermi="['system:user:add']"` |
| `v-hasRoles` | 角色控制 | `v-hasRoles="['admin']"` |
| `v-copyText` | 复制文本 | `v-copyText="text"` |

### 3. VXE-Table
- 高性能表格组件
- 适合大数据量（10万+ 行）
- 支持虚拟滚动、单元格编辑、Excel 导出
- 项目在用户选择、角色选择等组件中使用
